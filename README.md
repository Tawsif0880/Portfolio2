# Portfolio2

A multi-page personal portfolio website built with HTML, CSS, and Bootstrap 5.

## Overview

This project presents the portfolio of Tawsif Ahmed, including:

- Home page with profile summary and career direction
- About page with background and interests
- Education page with academic timeline and performance highlights
- Projects page with featured and additional work
- Contact page with direct contact details and a static mail form

## Tech Stack

- HTML5
- CSS3
- Bootstrap 5.3.3 (via CDN)

## Project Structure

- index.html - Home page
- about.html - About section
- education.html - Education timeline and academic details
- projects.html - Featured and past projects
- contact.html - Contact details and message form
- styles.css - Shared styling across all pages

## Features

- Responsive layout for desktop and mobile
- Consistent navigation across all pages
- Custom visual theme with gradients and card-based sections
- Static contact form using mailto
- Clean and readable content hierarchy

## Getting Started

1. Clone the repository:

```bash
git clone https://github.com/Tawsif0880/Portfolio2.git
```

2. Open the project folder.

3. Open `index.html` in your browser.

No build tools or package installation are required.

## Deployment

You can deploy this project using:

- GitHub Pages
- Netlify
- Vercel (static hosting)
